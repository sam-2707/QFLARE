## Slide Design Guidelines

### **Visual Design Principles**

#### **1. Consistent Branding**
```
Color Palette:
• Primary: #2C3E50 (Dark blue-gray)
• Secondary: #3498DB (Bright blue)  
• Accent: #E74C3C (Red for warnings/threats)
• Success: #27AE60 (Green for achievements)
• Background: #FFFFFF (White) or #F8F9FA (Light gray)

Typography:
• Headers: Montserrat Bold, 32-44pt
• Subheaders: Montserrat Medium, 24-28pt
• Body text: Open Sans Regular, 18-20pt
• Code/Technical: Fira Code, 16-18pt

Logo Placement:
• Top right corner on all slides
• Consistent sizing (80px height)
• High contrast against background
```

#### **2. Layout Templates**

**Title Slide Template:**
```
[Logo - Top Right]
[Large Title - Center, Bold, 48pt]
[Subtitle - Center, 32pt]  
[Presenter Info - Bottom Center]
[Date/Venue - Bottom Right]
```

**Content Slide Template:**
```
[Slide Title - Top Left, 32pt]
[Logo - Top Right]
[Content Area - Left 60%, Bullet points or text]
[Visual Area - Right 40%, Diagram or chart]  
[Slide Number - Bottom Right]
```

**Full-Screen Diagram Template:**
```
[Slide Title - Top Center, Overlay on image]
[Full-screen diagram/chart]
[Key annotations - Overlay callout boxes]
[Logo - Semi-transparent, bottom right]
```

#### **3. Visual Hierarchy Rules**

**Information Density:**
- Maximum 6-8 bullet points per slide
- Maximum 50 words per slide for executive presentations
- Use progressive disclosure for complex topics
- White space minimum: 25% of slide area

**Font Sizing:**
- Presentation venue distance rule: Font size = Distance in feet / 2
- Minimum readable size: 18pt for body text
- High contrast ratios: 7:1 minimum for accessibility

### **Technical Diagram Standards**

#### **Diagram Quality Requirements:**
```
Resolution: 300 DPI minimum for print, 150 DPI for screen
Format: PNG with transparency for overlays
Color coding: Consistent across all diagrams
Annotations: Clear, readable labels with connecting lines
Scale: Appropriate for slide dimensions (16:9 aspect ratio)
```

#### **Diagram Integration:**
- Use our generated diagrams as primary visuals
- Customize annotations for specific audiences
- Create simplified versions for executive presentations
- Maintain technical accuracy while improving readability
